# main_validation

This directory is the curated 10-run validation result set for eBeeMobile.

It contains the report-ready artifacts used to compare eBeeMobile burst-derived proxy metrics against non-invasive Android ground truth. The raw per-run workload captures remain local because they are large trace artifacts; the published files here are the compact summaries, validation tables, pseudo-request export, and figures needed to inspect the result.

Start with `report.md` for the generated narrative report, including workload summaries, validation target notes, best-fit proxy results, and links to the generated figures.

## Collection

The dataset was collected on a Google Pixel 9 running Android 15, with 10 repetitions of the four workload families:

- `workload_a`: idle baseline
- `workload_b`: app launch burst with Settings, browser `about:blank`, and Gallery launches
- `workload_c`: cold-cache Pexels page load followed by scripted swipes
- `workload_d`: cold-cache Pexels page load followed by Home and a background wait window

The runner captured:

- syscall traces for burst reconstruction
- eBPF monitor outputs for file activity, page allocation order, and allocation latency
- `am start -W` launch ground truth for Workload B
- `dumpsys gfxinfo` frame and jank ground truth for Workload C
- `dumpsys meminfo` memory ground truth for Workloads C and D

## Included Files

- `report.md`: generated analysis report with workload summaries, validation tables, and figure links
- `raw_summary.csv`: averaged raw eBPF monitor counters by workload
- `derived_metrics.csv`: derived file activity and memory/allocation metrics by workload
- `burst_summary.csv`: burst-derived pseudo-request metrics by workload
- `pseudo_requests.csv`: compact row-per-burst export reconstructed from syscall traces
- `episode_summary.csv`: launch, scroll, and background episode rows with proxy and ground-truth fields
- `launch_episode_summary.csv`: Workload B launch-only episode rows
- `launch_validation_summary.csv`: compact best-fit launch validation summary
- `launch_validation.csv`: per-proxy launch validation metrics at the default burst gap
- `launch_gap_sweep.csv`: launch validation metrics across burst gaps
- `gap_sweep_validation.csv`: compatibility copy of the launch gap sweep
- `scroll_validation.csv`: scroll validation metrics at the default burst gap
- `scroll_gap_sweep.csv`: scroll validation metrics across burst gaps
- `memory_validation.csv`: memory validation metrics at the default burst gap
- `memory_gap_sweep.csv`: memory validation metrics across burst gaps
- `comparison_ratios.csv`: workload-to-workload descriptive comparison ratios
- `correlation_points.csv`: compact workload-level export for downstream plotting
- `figures/`: SVG validation figures generated by the analyzer

## Excluded Local Artifacts

The following files exist in the local run directory but are intentionally kept out of Git:

- `workload_*/run_*/syscall_trace.txt`
- `workload_*/run_*/file_stats.txt`
- `workload_*/run_*/page_order.txt`
- `workload_*/run_*/alloc_latency.txt`
- `workload_*/run_*/metadata.txt`
- raw `ground_truth_*.txt` files

Those raw files are useful for re-analysis and debugging, but the full local run is about 190 MB and is not necessary for reading the released result.

## Primary Launch Result

For Workload B launch latency, the best overall eBeeMobile proxy for `am start -W` `TotalTime` was `throughput_bursts_per_s` at a 20 ms burst gap:

- `N = 30` launch episodes
- Pearson `r = -0.922793`
- Spearman `r = -0.883224`
- MAE `9.044127 ms`
- RMSE `10.996314 ms`

The best latency-shaped proxy was `avg_burst_latency_ms` at the same 20 ms burst gap:

- Pearson `r = 0.913852`
- Spearman `r = 0.876322`
- MAE `9.191823 ms`
- RMSE `11.588576 ms`

These values compare eBeeMobile inferred metrics directly against ground truth; they are not workload-vs-idle baseline comparisons.
